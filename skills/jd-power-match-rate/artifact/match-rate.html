Data source: Google Cloud's BigQuery, table trident-funding.jd_power_matching.daily_match_rate (a daily rollup of the underlying per-application enrichment_events table), filtered to environment = 'production'. Attempt/match counts are independent per field — a record with no value for a field is excluded from that field's denominator rather than counted as unmatched. Trim ID counts reflect whether a JD Power ModelTrimID was resolved, which only happens on a full model match — for boats this is currently identical to the model match count; for engines it can differ slightly.
